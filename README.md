# BETWEEN — Business Concept Studio

A static, responsive GitHub Pages website for betweenorigin.com.

## Publish
Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the root of your GitHub repository. Enable GitHub Pages from the main branch root.

## Domain
Add `betweenorigin.com` in GitHub Pages > Custom domain, then configure DNS at your domain registrar following GitHub's current documentation. Do not change existing DNS records until ready.

## Contact
All consultation buttons open an SMS draft addressed to (503) 765-0864. Visitors must send the text themselves.

## Design
Celestial midnight aesthetic with a glowing moon illustration made in CSS. The previously approved black-and-white BETWEEN logo remains in the studio section. No form or backend is required.

## Before launch
Check business name/trademark clearance and verify contact number, service wording, and SMS links on mobile.
